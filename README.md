# Shipping with AI

Companion code for [Shipping with AI](https://shippingwithai.quora.com/), notes from building and shipping AI features in real products, by [Sayam Jain](https://www.sayamjain.com).

Each folder is a small, runnable experiment behind one article. Data is synthetic; nothing here contains real conversations or keys.
